Model Context Protocol (MCP) 15 Araç Aktif

Geliştirici & AI Entegrasyon Rehberi

Electra, harici yapay zeka asistanlarının (Cursor, Claude Desktop, Antigravity, Windsurf vb.) atölye stoklarınızı sorgulayabilmesi, sağlam/arızalı parçalarınızı kontrol edebilmesi ve Robotistan üzerinden eksikleri tespit edip taslak siparişler oluşturabilmesi için tam donanımlı bir Model Context Protocol (MCP) sunucusuna sahiptir.

AI Asistanı Yapılandırması (Config)

Aşağıdaki JSON yapılandırmalarını AI editörünüzün ayar dosyasına ekleyerek Electra MCP sunucusunu anında aktif edebilirsiniz.

Canlı HTTPS / SSE URL (Cursor, Windsurf, Web AI)

⚡ ÖNERİLEN • SIFIR KURULUM

Python veya dosya indirmeden, doğrudan canlı sunucu URL'si ile bağlanın.

Dosya: .cursor/mcp.json veya Cursor Ayarları > Features > MCP: 

{
  "mcpServers": {
    "electra": {
      "url": "https://electra.matelab.dev/mcp?token=alp236330"
    }
  }
}

SSE protokolü tercih eden araçlar için: https://electra.matelab.dev/sse?token=alp236330

Claude Desktop (Uzak Köprü / Remote)

Claude Desktop'ı uzaktaki canlı sunucuya bağlar (stdio -> HTTPS köprüsü): 

{
  "mcpServers": {
    "electra": {
      "command": "python3",
      "args": [
        "/Users/emrullahardic/Documents/antigravity/nifty-tesla/mcp_server.py",
        "--remote",
        "https://electra.matelab.dev/mcp",
        "--token",
        "alp236330"
      ]
    }
  }
}

Yerel Python Modu (Local stdio)

İnternet olmadan, doğrudan bilgisayarınızdaki yerel SQLite dosyasını kullanır: 

{
  "mcpServers": {
    "electra": {
      "command": "python3",
      "args": [
        "/Users/emrullahardic/Documents/antigravity/nifty-tesla/mcp_server.py"
      ]
    }
  }
}

Sunucu Üzerinden Uzak Bağlantı (SSH Bridge)

SSH anahtarınız ile doğrudan ms sunucusundaki Python sürecini başlatır: 

{
  "mcpServers": {
    "electra-prod": {
      "command": "ssh",
      "args": [
        "ms",
        "python3",
        "/var/www/electra/mcp_server.py"
      ]
    }
  }
}

Dahili MCP Araçları (15 Tools)

AI asistanınız bu araçları otomatik olarak algılar ve sohbette ihtiyaç duyulduğunda arka planda çalıştırır.

electro_plan_project_draft_order AI Planlama

Proje fikrini analiz eder, eldeki sağlam/arızalı parçaları eşleştirir, eksikler için Robotistan'da stok ve fiyat arar ve otomatik bir Draft Sipariş kaydeder.

Parametreler: project_description (str)
electro_suggest_project_components Stok Analizi

Devre fikrini dinler; elinizdeki sağlam parçaları, yerlerini ve adetlerini çıkarır. Arızalı parçalar hakkında kullanıcıyı uyarır.

Parametreler: project_description, check_robotistan
electro_search_inventory Arama

İsim, değer (10k, 100nF), kılıf (DIP-8, 0805) veya saklama konumuna göre atölye stoğunda akıllı arama yapar.

Parametreler: query, category, status, location
electro_create_draft_order Draft

AI veya kullanıcı tarafından belirlenen ürün kalemleriyle yeni bir taslak sipariş listesi oluşturur.

Parametreler: title, description, items[]
electro_list_draft_orders Draft

Kayıtlı tüm taslak sipariş listelerini, tahmini tutarlarını ve durumlarını getirir.

Parametreler: status (draft, ready, ordered)
electro_apply_draft_order_to_cart Aktarım

Belirtilen taslak siparişteki tüm ürünleri tek tıkla canlı Robotistan sepetine dönüştürür.

Parametreler: draft_id (int)
electro_search_robotistan Scraper

Robotistan üzerinde canlı arama yapar. Ürün linki, aktif stok durumu ve anlık TL fiyatını çeker.

Parametreler: query, only_in_stock, limit
electro_get_defective_parts Arıza Takibi

Arızalı, bozuk veya test bekleyen parçaları ve arıza notlarını listeler.

Parametreler: Yok
electro_add_component Envanter

Sohbet sırasında kullanıcının atölyesine yeni bir elektronik parça ve saklama konumu ekler.

Parametreler: name, category, value, quantity, location
electro_update_stock Envanter

Stok miktarını artırır/azaltır veya parça durumunu (working, defective, salvage) günceller.

Parametreler: component_id, delta, status
electro_get_inventory_summary Özet

Atölyenin toplam çeşit, sağlam/arızalı sayıları ve kritik stok uyarılarını markdown formatında özetler.

Parametreler: Yok
electro_add_to_cart Sepet

Robotistan sepetine doğrudan ürün ekler (fiyat, link ve ürün ID bilgisiyle).

Parametreler: title, url, price, product_id

REST API & Kimlik Doğrulama (cURL)

HTTP Basic & Bearer Token

Kendi Python / Node.js scriptlerinizden veya cURL üzerinden Electra REST API'sine erişirken kimlik doğrulama başlığı gereklidir.

1. Stok İstatistiklerini Çekme (Basic Auth): 
curl -s -u admin:alp236330 https://electra.matelab.dev/api/stats
2. Parça Arama: 
curl -s -u admin:alp236330 "https://electra.matelab.dev/api/components?q=ESP32"
3. Taslak Siparişleri Getirme: 
curl -s -u admin:alp236330 https://electra.matelab.dev/api/draft-orders
